## Overview

NewWorks is a development workspace where I experiment with **web interfaces, JavaScript behaviour, visual components and frontend ideas**.

It contains practical experiments and reusable pieces developed while learning and building for the web.

## 🧰 Areas

- HTML & CSS interfaces
- JavaScript interactions
- UI experiments
- Reusable frontend components
- Visual effects and web utilities

## 📚 Purpose

This repository is an **experimental archive**, not a primary portfolio project. Individual ideas that become production-ready should be moved into focused repositories with their own documentation, tests and deployment workflow.
